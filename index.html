Built from first principles

No black box.
Just math, code, and curiosity.

Instead of using a machine-learning library, I implemented logistic regression myself to understand every step—from cleaning the data to standardizing features and updating model weights with gradient descent.

View dataset ↗ Watch demo ↗
  1. 01

    Clean and prepare

    Normalized labels, converted numeric fields, and handled missing values with Pandas.

  2. 02

    Engineer features

    Created loan-to-income, loan-to-asset, and log-transformed financial features.

  3. 03

    Train the model

    Used an 80/20 split and 1,000 gradient-descent iterations with a custom sigmoid function.

  4. 04

    Make it useful

    Added practical FICO, income-share, and leverage adjustments to the educational estimate.
